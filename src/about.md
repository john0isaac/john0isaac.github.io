I'm **John Isaac Aziz**, a software engineer based in Cairo, Egypt. Online I go by **john0isaac**. I build
production-grade AI systems and Python backends, and I spend a lot of my spare time on open source and on
teaching developers through blog posts, talks, and Microsoft Learn content.

## What I do

I'm currently a **Senior AI Software Engineer at [Lyah](https://lyah.ai)**, an AI-powered
EdTech platform. I designed and built the framework behind Lyah's course generation, tutoring, and copilot agents.
It's a modular LangGraph system in Python with a provider-agnostic multi-LLM layer (OpenAI, Anthropic, Google), Celery
orchestration, and Opik observability. I also built the course and lecture generation agents, an AI tutor with
retrieval-augmented generation (RAG), and an LLM evaluation and prompt-optimization pipeline.

Before Lyah, I worked as a Software and Data Engineer at **Orange Business**. There I built FastAPI and React
applications, RAG pipelines with pgvector and OpenAI, and Kubernetes and Helm automation, and led development on
several internal applications. Earlier roles at **Fabrica Dev** and **GEMINDZ** covered full-stack Python and Vue.js
development, device automation, and testing infrastructure.

Most of my work falls into these areas:

- **AI engineering:** multi-agent systems, RAG, LLM evaluation, and prompt optimization with LangGraph, LangChain,
  Semantic Kernel, and Azure OpenAI.
- **Backend and full-stack development:** Python (FastAPI, Flask, Django, Quart) with Vue.js or React.
- **Cloud and DevOps:** Azure, Kubernetes, Docker, Terraform, the Azure Developer CLI, and GitHub Actions and GitLab CI/CD.
- **Developer tooling:** Python packages, CI automation, and testing infrastructure.

## Open source

I maintain [CacheLib](https://github.com/pallets-eco/cachelib/), a caching library in the Pallets Eco ecosystem. I also
wrote [markdown-checker](/markdown-checker), a Python package for validating links in Markdown. It runs in Microsoft
repositories such as [Generative AI for Beginners](https://github.com/microsoft/generative-ai-for-beginners) and at its
peak had about 45k monthly downloads. I've contributed features and bug fixes to the
[Azure Developer CLI](https://github.com/Azure/azure-dev), and I've published many
[Azure sample apps and templates](/projects/). The code for all of these is on
[GitHub](https://github.com/john0isaac).

## Community and teaching

I was a **Microsoft MVP** and a **Gold Microsoft Learn Student Ambassador**. I've written
[Microsoft Learn modules](https://learn.microsoft.com/training/modules/introduction-large-language-models/) on large

[Contributor Stories](https://aka.ms/contributor-stories/john-aziz) series. I led the Azure Egypt User Group and
